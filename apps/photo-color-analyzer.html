03 · CALIBRATION

표준곡선 그리기

표준액 시료를 체크하고 알려진 농도를 입력하세요. x축은 농도, y축은 선택한 사진 분석값입니다.

표준액으로 사용농도 (0 이상)분석값

서로 다른 사진은 노출·화이트밸런스·조명을 동일하게 맞춰야 비교할 수 있습니다. 절편을 포함한 최소제곱 선형회귀(y = ax + b)입니다. R²가 높아도 반복 오차·측정 범위·별도 시료의 예측 정확도를 함께 확인하세요. 농도는 같은 단위로 입력하며, 단위 변경은 숫자를 환산하지 않습니다.

사진 분석 공통 안내

촬영 조건을 같게

동일한 큐벳과 액면 높이, 균일한 조명·배경을 사용하세요. 여러 시료를 한 장에 촬영하고 카메라의 노출·화이트밸런스·거리·각도를 고정하세요. 반사광, 기포, 그림자, 큐벳 모서리는 피하세요. 필터·HDR·자동 보정은 가능하면 끄세요.

비교에서 정량 분석으로

알려진 농도의 표준액과 실험 시료를 같은 조건에서 촬영하세요. 표준액을 선택하고 농도를 입력하면 지표별 회귀식과 R²를 비교할 수 있습니다. 농도 환산에는 검증한 측정 범위를 사용하세요. 이 앱은 농도·반응속도를 자동 환산하지 않습니다.

[예시] 녹말-아이오딘 반응 사진 분석 팁

알려진 농도의 녹말 표준액에 같은 양의 I₂KI를 넣고 최종 부피와 발색 후 촬영 시간을 맞춰 표준곡선을 만드세요. 시간별 반응 시료도 같은 조건으로 발색·촬영합니다. 각 채널의 농도별 변화를 확인해 분석 지표를 선택하세요.

평균 밝기와 상대 휘도의 차이

평균 밝기는 R·G·B를 같은 비중으로 평균한 값(0–255)입니다. 상대 휘도는 sRGB의 비선형성을 보정하고 녹색에 가장 큰 가중치를 주어 계산한 값(0–100)입니다.

예: 순수 빨강(255, 0, 0)과 순수 초록(0, 255, 0)은 평균 밝기가 둘 다 85지만, 상대 휘도는 각각 21.26과 71.52입니다. 색 변화 분석에서는 어느 항목이 표준액 농도를 잘 구분하는지 비교해 선택하세요.

평균 밝기 = (R + G + B) / 3. 상대 휘도는 각 픽셀의 sRGB 채널을 선형화한 뒤 Y = 0.2126Rₗ + 0.7152Gₗ + 0.0722Bₗ로 계산하고, 원 내부 평균에 100을 곱합니다. 0은 검정, 100은 흰색입니다. 실제 광학 휘도(cd/m²)나 특정 파장의 흡광도가 아닙니다.

테두리·번호는 별도 층에 그리므로 분석값에 포함되지 않습니다. 이미지 가장자리에서는 영역이 잘리며 원 지름과 실제 사용한 픽셀 수를 표시합니다. 픽셀 중심이 원 안에 있는 경우만 분석합니다. 알파값이 255 미만인 반투명·투명 픽셀은 제외합니다. 원본을 축소하지 않고 브라우저의 sRGB 캔버스에서 읽습니다.
