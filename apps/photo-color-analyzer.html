평균 밝기와 상대 휘도의 차이

평균 밝기는 R·G·B를 같은 비중으로 평균한 값(0–255)입니다. 상대 휘도는 sRGB의 비선형성을 보정하고 녹색에 가장 큰 가중치를 주어 계산한 값(0–100)입니다.

예: 순수 빨강(255, 0, 0)과 순수 초록(0, 255, 0)은 평균 밝기가 둘 다 85지만, 상대 휘도는 각각 21.26과 71.52입니다. 색 변화 분석에서는 어느 항목이 표준액 농도를 잘 구분하는지 비교해 선택하세요.

평균 밝기 = (R + G + B) / 3. 상대 휘도는 각 픽셀의 sRGB 채널을 선형화한 뒤 Y = 0.2126Rₗ + 0.7152Gₗ + 0.0722Bₗ로 계산하고, 원 내부 평균에 100을 곱합니다. 0은 검정, 100은 흰색입니다. 실제 광학 휘도(cd/m²)나 특정 파장의 흡광도가 아닙니다.

테두리·번호는 별도 층에 그리므로 분석값에 포함되지 않습니다. 이미지 가장자리에서는 영역이 잘리며 원 지름과 실제 사용한 픽셀 수를 표시합니다. 픽셀 중심이 원 안에 있는 경우만 분석합니다. 알파값이 255 미만인 반투명·투명 픽셀은 제외합니다. 원본을 축소하지 않고 브라우저의 sRGB 캔버스에서 읽습니다.
